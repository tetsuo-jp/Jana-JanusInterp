Weekly Extension Summary

This page summarizes the parts extended during the last week (based on commits from 2026-03-13 through 2026-03-15).

The main theme was turning the Python implementation under src-python/ into a release-candidate interpreter with a browser playground and broader language coverage.

Try the playground

1. Python parity reached release-candidate state

The Python interpreter now covers the main parity backlog against the Haskell reference implementation.

  • Debugger reverse stepping was aligned for deeper step-back flows.
  • from, iterate, local, and procedure-boundary reverse behavior were matched.
  • Error and backward type behavior were checked against Haskell-observed output.
  • A one-command release-candidate verification entrypoint was documented.

2. New frontend-accessible language features

The Python backend picked up several extensions that are now available through the web playground as well.

  • Preprocessor support: object macros, function macros, includes, source maps, escapes, and conditionals.
  • struct support: declarations, field access, updates, procedure arguments, formatting, and validation.
  • Extended example coverage, including examples/build-dict.ja for combined macro and struct usage.

3. Browser playground for src-python/

The existing web UI was wired to the Python interpreter so the current implementation can be used from a browser.

  • execute.php runs python3 -m jana_py.cli.
  • load.php serves example programs.
  • save.php stores shareable snippets.
  • The UI keeps support for invert mode and 32-bit modular integers.

Follow-up fixes aligned parser EOF positioning and test expectations with the Haskell reference, while also finalizing the preprocess and struct-related test surfaces.

What this means for users

  • You can now run the current Python Jana implementation from the browser instead of only from the CLI.
  • More programs parse and execute thanks to preprocess and struct support.
  • Debugger behavior and failure reporting are closer to the Haskell interpreter.
  • There is a clearer verification path for future releases and regressions.
