
# Plan for Continuing Syntax Standardization and Feature Implementation

## Overall Goal:
Continue the standardization of Janus syntax towards a C-like style, addressing parser and formatter issues, and ensuring example files are updated.

## Detailed Plan:

1.  **Implement Preprocessor Directive Handling:**
    *   **Objective:** Add support for `#include` and `#define` directives in the Python parser (`src/jana_py/parser.py` or `src/jana_py/preprocess.py`) to correctly parse files like `examples/self-interp/modern_interpreter_cstyle.ja`.
    *   **Sub-tasks:**
        *   Analyze the current preprocessing logic in `src/jana_py/preprocess.py`.
        *   Identify how `#include` and `#define` are handled (or should be handled) according to C preprocessor semantics.
        *   Modify the parser or preprocessor to correctly interpret these directives.
        *   Update relevant test files if necessary.

2.  **Standardize `switch` Statement Syntax:**
    *   **Objective:** Ensure `switch` statements fully adhere to C-style syntax, including requiring `break;` after each `case` and `default` block, and correctly handling the statement termination.
    *   **Sub-tasks:**
        *   Modify `src/jana_py/parser.py` to enforce `break;` in all `switch` cases and the default block.
        *   Modify `src/jana_py/format.py` to ensure consistent formatting of `switch` statements with `break;`.
        *   Update or add tests in `src/tests/` for `switch` statement parsing and formatting.

3.  **Refactor `local`/`delocal` Syntax to C-style Blocks:**
    *   **Objective:** Adapt the `local`/`delocal` syntax to use C-style block syntax (`{...}`) for improved clarity and consistency.
    *   **Sub-tasks:**
        *   Modify `src/jana_py/parser.py` to parse `local ... { ... } delocal ...;` structures.
        *   Modify `src/jana_py/format.py` to output this C-style block syntax for `local`/`delocal` statements.
        *   Update or add tests for this syntax.

4.  **Convert `iterate` to C-style `for` Loops:**
    *   **Objective:** Replace `iterate` statements with their C-style `for` loop equivalents (e.g., `for (init; condition; update) { ... }`).
    *   **Sub-tasks:**
        *   Modify `src/jana_py/parser.py` to correctly parse the C-style `for` loop syntax.
        *   Modify `src/jana_py/format.py` to output the C-style `for` loop syntax.
        *   Update or add tests for `for` loop parsing and formatting.

5.  **Update Example Janus Files:**
    *   **Objective:** Ensure example files (`.ja`) in `examples/` and `basicExamples/` that use old syntax (e.g., `procedure`, old `if/fi`, old `iterate`, `show()`) are updated to the new C-style syntax.
    *   **Sub-tasks:**
        *   Identify example files that need updating.
        *   Apply the syntax changes identified in the previous steps to these files.

6.  **Run Regression Tests:**
    *   **Objective:** Verify that all changes are integrated correctly and do not introduce regressions.
    *   **Sub-tasks:**
        *   Execute the full regression test suite (`make rc`).
        *   Address any new failures that arise.
